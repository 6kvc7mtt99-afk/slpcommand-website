# Manual web actions

**23 August 2026.** Only things that cannot be done from this repository.
Everything code-owned — metadata, sitemap, robots, canonical, hreflang, JSON-LD,
security headers, accessibility, the proxy allowlist — is done and is in git.

Format is deliberate: location, exact action, why, expected result, how to
verify. Not "improve SEO".

---

## BLOCKER

### 1. Deploy the web branch

**LOCATION:** your terminal, then Cloudflare picks it up
**EXACT ACTION:**
```bash
cd "~/Developer/SLP COMMAND/01-CODE/WEB/slpcommand-website"
git push origin feature/slpcommand-web-platform
```
**WHY:** the security headers, the Academy completion beacon, the honest Coach
copy and the two published subprocessors are all committed and unpushed. None of
them exists for a visitor yet.
**EXPECTED RESULT:** Cloudflare builds and deploys the branch it tracks.
**HOW TO VERIFY:**
```bash
curl -sI https://slpcommand.com/ | grep -i strict-transport-security
# expected: max-age=63072000; includeSubDomains; preload
# today: nothing
```
That header is the deployment tell — it exists only in this work.

## IMPORTANT

### 2. Verify the site in Google Search Console

**LOCATION:** <https://search.google.com/search-console> → Add property →
Domain → `slpcommand.com`
**EXACT ACTION:** choose DNS verification, copy the `TXT` record Google shows,
add it in Cloudflare → DNS → Records, then press Verify.
**WHY:** it blocks *all* organic measurement. The technical foundation is
already in place — sitemap, robots, canonical, hreflang with x-default on the
localized SLP-2/SLP-3 pairs, JSON-LD — and none of it can be observed without
this. Roughly twenty minutes.
**EXPECTED RESULT:** property verified; Coverage and Performance begin
populating within a few days.
**HOW TO VERIFY:** Search Console → Sitemaps → submit
`https://slpcommand.com/sitemap.xml` and see it accepted with its URL count.

### 3. Submit the sitemap

**LOCATION:** Search Console → Sitemaps
**EXACT ACTION:** submit `https://slpcommand.com/sitemap.xml`
**WHY:** discovery. The sitemap is generated by `app/sitemap.ts` and is live and
returning 200 today; nothing has ever told Google it exists.
**EXPECTED RESULT:** status "Success" with the discovered URL count.
**HOW TO VERIFY:** the count matches `curl -s https://slpcommand.com/sitemap.xml | grep -c "<loc>"`.

### 4. Decide the enforcing Content-Security-Policy

**LOCATION:** `next.config.ts` (code) — but it needs a decision first
**EXACT ACTION:** the header block currently ships `frame-ancestors 'none'` and
nothing else. A full policy needs two things settled: a nonce threaded through
`middleware.ts` for the inline scripts Next.js emits, and the exact ElevenLabs
and LiveKit hosts the Coach opens WebSockets to, enumerated in `connect-src`.
**WHY:** it was deliberately not guessed. A wrong `script-src` breaks the
paywall; a wrong `connect-src` breaks the Coach. Both are outages, not warnings.
**EXPECTED RESULT:** a policy that can be shipped in `Report-Only` first, with a
report endpoint, and promoted to enforcing once it is quiet.
**HOW TO VERIFY:** `Report-Only` for a week with zero violations from real
traffic, then flip.
